# Cheniere Energy

> Cheniere Energy, Inc. is the largest producer and exporter of liquefied natural gas in the
> United States, operating the Sabine Pass LNG terminal in Louisiana and the Corpus Christi LNG
> terminal in Texas. It also owns and operates two FERC-regulated interstate natural gas
> pipelines: Cheniere Creole Trail Pipeline, L.P. and Cheniere Corpus Christi Pipeline, L.P.

Generated by API Evangelist on 2026-09-06 from probes of Cheniere's public surface. Cheniere does
not publish an llms.txt of its own; /llms.txt returns 404 on www.cheniere.com,
lngconnection.cheniere.com and lngconnectionapi.cheniere.com.

## What Cheniere actually exposes to machines

Cheniere has no developer program, no developer portal, no API documentation, no SDK, no signup
and no published OpenAPI. It nonetheless operates ONE public, unauthenticated JSON API: the
informational-postings API behind its LNG Connection pipeline site. It exists because FERC
18 CFR 284.13 requires an interstate pipeline to publish capacity, transactional reporting, the
Index of Customers, gas quality and operational notices where anyone can read them.

If you are looking for an API to Cheniere's LNG business — cargoes, contracts, terminal
schedules, production — there is none. Those are negotiated bilaterally.

## Cheniere LNG Connection — Pipeline Informational Postings API

- Base URL: https://lngconnectionapi.cheniere.com
- Human site: https://lngconnection.cheniere.com
- Authentication: none. No key, no OAuth, no signup.
- Cost: free. There is no pricing page because there is no API product.
- Format: JSON. All data operations are GET.
- Pipelines: tspNo=200 Cheniere Creole Trail Pipeline, L.P.; tspNo=400 Cheniere Corpus Christi
  Pipeline, L.P.
- CORS: restricted to https://lngconnection.cheniere.com. Server-side callers are unaffected.

### Start here

- https://lngconnectionapi.cheniere.com/api/Page/GetPages — the posting page tree and the list of
  pipelines served. No parameters.
- https://lngconnectionapi.cheniere.com/api/Capacity/GetCycles — the five NAESB nomination cycles
  (Timely, Evening, Intraday 1-3) you need as cycleId.
- https://lngconnectionapi.cheniere.com/api/LocationDownload/Get?tspNo=200 — the full location
  master list for a pipeline.

### Capacity (FERC 284.13(d))

- /api/Capacity/GetLocations?tspNo=&beginDate=&endDate=
- /api/Capacity/GetCapacity?tspNo=&beginDate=&cycleId=&locationId= — operationally available
  unscheduled capacity
- /api/Capacity/GetUnsubscribed?tspNo=&beginDate= — unsubscribed firm capacity

### Transactional reporting (FERC 284.13(b))

- /api/Transactional/GetFirm?tspNo=&beginDate=&endDate=
- /api/Transactional/GetInteruptible?tspNo=&beginDate=&endDate= (the single-'r' spelling is the
  provider's own)
- /api/Transactional/GetCapacityRelease — BROKEN. 404 on the one-parameter form the provider's own
  client uses, 500 on the dated form. Observed 2026-09-06.

### Index of Customers (FERC 284.13(c))

- /api/IndexOfCustomers/Quarter — list available quarters first
- /api/IndexOfCustomers/Get?firstDayOfQuarter=&tspNo=

### Gas quality

- /api/GasQuality/GetLocations?tspNo=&beginDate=&endDate=
- /api/GasQuality/GetGasQuality?tspNo=&beginDate=&endDate=&locationId=
- /api/DailyComingled/GetDailyComingled?tspNo=&beginDate=&endDate=

### Imbalances, notices and reference data

- /api/PostedImbalances/GetPeriods then /api/PostedImbalances/Get?tspNo=&period=
- /api/Notice/GetActiveSummaryNotices?companyId=
- /api/Station/GetStationsByCompanyId?tspNo=

## Traps you should know before you call it

- FIELD CASING IS MANGLED AND INCONSISTENT. NAESB element names serialize as tsP_NO, loC_ID,
  efF_DT_FROM, dunS_NUM, c02_PCT. Other endpoints use ordinary camelCase. The same logical field is
  spelled three ways across endpoints (tspNo / tsP_NO / companyId). Normalize keys on ingest.
- NO PAGINATION of any kind, and no way to detect a truncated result. Window by gas day.
- NO CACHING. Every response is Cache-Control: no-cache with no ETag and no Last-Modified, so
  polling costs a full transfer every time.
- NO VERSIONING, no deprecation policy, no changelog, no status page, no SLA.
- NO RATE-LIMIT HEADERS and no 429 observed — but also no published limit, so an undocumented one
  would be indistinguishable from a fault.
- ERRORS ARE NOT RFC 9457. You get {"message": "An error has occurred."} with no code and no
  request id.
- A 200 with a literal `null` body means "nothing attached" on the legend, footer and page-link
  endpoints.
- tspNo 600 and 800 route but return zero rows.
